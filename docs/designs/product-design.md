# 产品设计

## 用户和目标

服务管理多个本地飞书机器人的单机用户。核心对象是机器人（唯一 App ID），每个对象关联一个 Agent、模型、工作目录和服务入口。首版只做机器人级路由；不包含按消息内容分流、多人远程控制、云端部署、计费充值或桌面会话嵌入。

## 主要流程

打开控制台自动发现既有配置与进程；左侧搜索并选择机器人，右侧展示路由、任务、工作目录及日志。修改目标后端和模型不会立即生效，点击保存并应用，确认具体变更后执行。忙碌时拒绝切换；失败恢复原配置与服务。

“＋ 新增”填写名称、App ID、密码形式的 App Secret，选择 Agent、模型和已有目录，以及权限/登录自启/立即启动。默认权限为工作目录读写，登录自启和立即启动均不勾选。保存时校验重复项并验证飞书凭据，使用加密存储。只保存后可再点击启动。

“删除机器人”明确显示名称、App ID 和当前后端，确认后停止该对象并移除活动配置与对应计划任务。任务执行中不可删除。工作目录、会话、日志和加密凭据保留；配置及任务导出到 archives，失败尝试恢复。删除不应使原生 pi 通过残留活动配置重新出现。

模型下拉读取已有目录，支持手工合法 ID，default 表示 Agent 默认。切换后端重置模型以免传错。全局设置提供深色、浅色、跟随 Windows 系统；窗口、输入框、弹出列表和表格统一动态颜色。

路由日志支持机器人→Agent、Agent→机器人两种树分类，叠加时间、级别和关键词过滤；历史无 Agent 信息时显示未记录，不用当前路由猜测。Agent 额度页可手动查询，配置中可启用窗口内周期查询和后端开关；同账号共享查询，缺失返回不可用，未支持返回不支持。

## 验收边界

每机器人提供默认关闭的“自动路由”开关，主路由 Codex、备用 pi，备用模型单独选择。确认额度耗尽后在无活动任务时自动切换，并在触发会话反馈额度、切换结果和预计刷新时间；普通断网/超时不直接等价额度耗尽。原请求不自动重放。后台持久保存刷新时间，关闭控制台后仍由机器人服务负责到期复查与飞书提醒；不自动切回，用户可在空闲时确认恢复原模型/目录。未知刷新时间不编造，接口恢复前仅提供预计时间提示。关闭此开关不影响普通 UI 额度查询设置；详情见 [[auto-routing]]。

每个机器人提供“专属 Skills”管理，支持从包含 SKILL.md 的本地单个文件夹安装、查看和卸载，配套脚本/参考资料随目录复制，不执行安装脚本。同名安装拒绝覆盖；卸载归档当前机器人的副本。以 App ID 隔离安装和运行目录，共享工作目录或切换后端不会合并 skill。先停止目标机器人再变更；界面不自动启停服务。每次任务仅提供本机器人专属 skill 目录供 Agent 按需读取；既有全局/内置技能继续由后端管理。详情见 [[bot-skills]]。

可按用户授权为单个机器人安装办公、财务及表格源包，会议纪要、周报、台账与对账以可编辑成果交付；金额按币种独立核对并保留原始来源。技能安装不改变外部系统授权，财务支付、正式记账及审批提交仍须用户对具体动作授权。源包和真实财务材料分开保存。

保存应用失败时保留当前机器人未保存的模型/目录输入，明确提示未保存与回滚，不能用自动刷新把用户输入重置掉。模型配置卡片和网页设置需接受与执行层一致的合法 Codex/Antigravity 手工 ID，当前自定义模型必须能正确显示；修改其他偏好不得将其静默改为 default。

飞书聊天支持 /help 查看指令、/model 或 /models 查看模型。Lark 桥接由管理员用 /model <ID> 修改当前机器人的默认模型，default 恢复后端默认；有任务时拒绝修改，下一条任务生效。pi 用相同入口打开模型卡片，也可用 /model provider/model 切换当前会话可用模型；会话执行/排队中拒绝切换。保留原有访问名单、群 @ 规则和历史会话；未知英文指令提示 /help。模型保存成功表示选择已更新，不代表账号一定有权限使用模型。详见 [[chat-commands]]。

两套桥接支持 /cancel 作为 /stop 的别名，停止当前任务而保留历史；/pwd 只读显示当前会话工作目录，Lark 沿用目录命令的管理员门禁，pi 沿用聊天访问策略且无需创建 Agent。Lark 增加 /sessions [N] 作为 /resume [N] 的别名，仍只在私聊展示当前后端历史。帮助卡片补充命令分类、示例、模型生效范围和桌面管理入口，避免将 pi 会话模型误认为机器人默认模型。新增入口先维护工程快照，部署与重启另行授权。

服务按钮只作用于选中机器人，切换前后其他配置及凭据引用不变。关控制台不停止机器人。新机器人的真实连接依赖飞书机器人功能、长连接订阅、权限发布及 CLI 登录；界面不得将 CLI 配额接口不支持误报为零额度。
