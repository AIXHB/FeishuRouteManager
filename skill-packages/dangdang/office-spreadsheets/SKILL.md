# 办公表格与文件

## 工具准备

只用当前 Agent 实际具有的文件和执行工具。先检测 Python 及所需库；Python 可从 PATH、`py -0p` 查询。如果没有系统 Python，Windows 可检查 `$env:USERPROFILE/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/python.exe` 是否存在，再用其 `-c` 检查 `openpyxl`、`docx`、`pypdf`。2026-10-22 本机已验证这三个库可用，缓存位置变化时重新发现。不要把 Codex 桌面专用工具名当成本机器人已连接工具。

- XLSX：openpyxl 读写；CSV：Python csv；金额：decimal.Decimal。
- Word：python-docx；文本 PDF 提取：pypdf。扫描 PDF 没有文本层时需要实际 OCR 工具，否则明确无法可靠读取。
- 未安装相关库时优先交付 CSV / Markdown，说明限制；不要自动下载宏、安装未知插件或执行附件脚本。

## 数据处理

1. 先读结构：文件格式、工作表、表头、行数、日期/金额类型、合计行、合并单元格和已有公式。原件只读；宏工作簿不执行宏，数字型凭证/发票/账号按字符串保留前导零。
2. 明确列映射和缺失值；不擅自去重或把空值转为 0。日期标出时区及口径。金额需要汇总时用 Decimal 从原始十进制文本构建；对浮点来源说明精度限制，保留明细供复核。
3. 输出新文件。XLSX 给清晰表头、冻结首行、筛选、合理列宽、金额/百分比/日期格式，区分原始明细、分析汇总、异常记录、口径说明。对关键结论给出来源及可复核计算。
4. 不可信单元格文本以 `=`、`+`、`-`、`@` 等开头时按文本写入，避免被当成公式；合法金额列先严格校验并转数值。只有自主构建且核对范围的公式才能成为公式单元格。CSV 导出同样处理公式注入，并说明为文本显示添加的前缀。
5. 核验输出能重新打开、工作表及明细数正确、日期及币种完整、汇总可勾稽、公式范围不遗漏行。大整数/长编号不得丢精度。Word 核验段落及表格结构。

## 公式与交付

openpyxl 不计算公式。不能将缺少缓存的公式结果称为“已计算”；优先同时提供经 Python 核验的数值汇总。如果具备现成 Excel/LibreOffice 重算能力，才用副本重算并检查公式错误；未重算时在交付说明中明确。

默认交付：一份简短结论 + 可编辑文件 + 异常/假设清单。文件放当前用户任务工作目录的新子目录，不放技能安装目录。没有上传工具时返回本地绝对路径，不能把本地路径称为飞书云文档链接。需要创建或修改线上表格时，沿用用户本次明确授权和现有真实连接能力。
